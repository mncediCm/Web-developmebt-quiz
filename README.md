# Web Development Quiz App

A responsive, dark-mode multiple-choice quiz covering HTML, CSS, and JavaScript.

## Features
- Seven multiple-choice questions
- 15-second countdown timer per question
- Automatic timeout and answer feedback
- Live score and animated progress bar
- Results screen with percentage and performance feedback
- Restart quiz button
- Responsive desktop and mobile layout

## Run locally
Open `index.html` in any modern web browser. No installation, server, or internet connection is required.
